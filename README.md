# remote-mouse

把手机变成 PC 的无线触控板 + 键盘。Server 装在电脑（Windows/macOS），Client 是手机 App（iOS/Android），同一 WiFi 下发现、密码认证后控制光标与键盘。

> 当前处于**设计调研**阶段，尚无代码。完整设计文档见 [`docs/`](docs/README.md)。
