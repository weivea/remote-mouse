# 00 — 项目概述

## 愿景
把手机变成 PC 的无线触控板 + 键盘。用户在家庭/办公室同一 WiFi 下，打开手机 App 即可发现电脑、输入密码连接，然后像用笔记本触控板一样移动光标、点击、滚动、打字，并能进行多媒体/演示等扩展控制。

## 核心能力（按优先级）
1. **同网段自动发现** server，无需手动输入 IP。
2. **密码认证**配对，连接安全（加密传输）。
3. **触控板模式**：相对移动、左右键、滚轮、多指手势。
4. **键盘输入**：文本、特殊键、快捷键。
5. **跨平台**：Server = Windows + macOS；Client = iOS + Android。
6. **锁屏控制（拉伸目标）**：锁屏下仍能控制并输入密码解锁（平台限制大，见 [09](09-lock-screen.md)）。

## 范围（In Scope）
- 局域网（LAN / 同一 WiFi）使用场景。
- 一台 Client 连一台 Server（1:1）；后续可扩展多 client。
- 鼠标、键盘、滚轮、基础手势、媒体键。

## 非目标（Out of Scope，至少初期）
- 公网/跨网段远程控制（无打洞/中继服务器）。
- 完整远程桌面（屏幕画面回传）——本项目只发输入，不传画面。
- 文件传输、剪贴板同步（可作后续可选模块）。
- 游戏级手柄/绝对定位精度。

## 关键约束与风险
| 约束 | 说明 | 影响 |
|------|------|------|
| OS 输入注入权限 | macOS 需 Accessibility 授权；Windows UAC/secure desktop 受限 | 首启需引导授权 |
| 锁屏注入限制 | Win 需 SYSTEM 服务；macOS 登录窗几乎不可注入 | 解锁功能 macOS 受阻，列为风险 |
| iOS 后台网络 | 后台保活/本地网络权限受限 | 连接保活需处理 |
| 网络多播 | 部分 WiFi/AP 隔离禁止 mDNS | 需 UDP 广播兜底 |
| 延迟 | 触控板手感对延迟敏感 | 选 UDP + 状态最新优先 |

## 成功标准（MVP）
- 同 WiFi 下手机 3 秒内发现电脑，密码连接成功。
- 触控板移动光标端到端延迟 < 50ms（局域网），主观“跟手”。
- 在 Win 与 Mac 已登录会话稳定打字/点击 30 分钟无断连。
