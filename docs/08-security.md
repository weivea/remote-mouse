# 08 — 安全

威胁背景：同 WiFi 可能有他人；本工具能注入键鼠（含密码），必须强认证+加密。

## 目标
- 仅授权设备可控；密码不明文存/传；防窃听、防重放、防仿冒；锁屏功能不降低 PC 安全门槛。

## 认证
- 连接密码/PIN（PC 设/显示）。
- 协议：**SPAKE2/SRP**（PAKE，密码不上线）；MVP 可 HMAC 挑战-响应（nonce+HMAC(KDF(pwd))）。
- 失败重试限速+锁定，防爆破。
- 配对后存设备密钥/证书，受信免密；可撤销。

## 加密
- 控制面 TLS（自签 + 配对锁定指纹/TOFU）。
- 数据面 UDP 用会话密钥 AEAD（AES-GCM/ChaCha20）；nonce+seq 防重放，过期丢。

## 密码存储
- 仅存 Argon2/scrypt 哈希；密钥进 mac Keychain / Win DPAPI。

## 锁屏安全
- 仅“代发输入”，不绕过认证；解锁=代输正确密码，需配对授权。
- 默认锁屏控制可关；可设“锁屏不输密码”。

## 隐私
- 纯 LAN、无云、无遥测；UDP 不传画面，泄露面小。

## 边界
- mDNS 暴露设备名（用中性名）；AP 隔离=不可达；手动 IP 仍需认证。
