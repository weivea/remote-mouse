# 10 — 迭代路线

分多次会话推进，每阶段可独立验收。

## M0 — 设计（当前）✅
- 调研 + docs/。下个会话从这继续。

## M1 — MVP 单平台直连
- Server(选一台，Mac 或 Win)：TCP 监听 + robotgo/enigo 注入。
- Client(Flutter)：手动输 IP，触控板移动+左键+滚动。
- 验收：手机移动光标、点击。无加密无发现。

## M2 — 发现 + 认证
- mDNS announce/浏览；密码 HMAC 认证；TLS。
- 验收：自动发现、密码连、错误被拒。

## M3 — 全输入 + 双平台 Server
- 右键/中键/拖拽/双指/键盘文本/快捷键/媒体；Win+Mac 都跑通。
- UDP 数据面 + 加密。验收：达标延迟、稳定打字。

## M4 — 体验 + 受信设备
- 灵敏度/手势/记住设备/重连/托盘自启。
- 验收：免密复连、配置生效。

## M5 — 锁屏（拉伸）
- Win SYSTEM 服务 secure-desktop 注入；mac 现状/硬件桥评估。
- 验收：Win 锁屏控制+解锁。

## M6 — 打磨发布
- 签名/公证/安装包，多设备测试。

## 后续可选
剪贴板、文件、多 server、横竖屏、绝对触控、Linux server、桌面 client。
