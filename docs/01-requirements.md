# 01 — 需求

## 1. 角色
- **Server**：装在 PC（Windows/macOS），监听网络，注入输入到本机。
- **Client**：手机 App（iOS/Android），采集触控/键盘，发信号。

## 2. 功能需求 (FR)

### 2.1 发现 / 连接
- FR-1 Client 启动后自动发现同网段所有 Server，列出名称/平台/IP。
- FR-2 支持手动输入 IP/端口兜底（mDNS 被阻时）。
- FR-3 首次连接需密码认证；可“记住此设备”免下次密码。
- FR-4 Server 端显示连接请求并可批准/拒绝（可选，受信设备自动通过）。
- FR-5 断线自动重连。

### 2.2 鼠标
- FR-6 相对移动（触控板模式），含加速度曲线。
- FR-7 左键单击/双击、右键、中键。
- FR-8 滚轮（垂直/水平）。
- FR-9 拖拽（按住移动）。
- FR-10 多指手势：双指滚动、双指右键、三指拖拽（可配置）。

### 2.3 键盘
- FR-11 文本输入（含中文 IME、emoji，走 unicode 直接注入）。
- FR-12 特殊键：Enter/Backspace/方向/Esc/Tab/功能键。
- FR-13 组合键/快捷键（Ctrl/Cmd/Alt/Shift + 键）。
- FR-14 媒体键：音量、播放/暂停、上下曲。

### 2.4 锁屏（拉伸）
- FR-15 锁屏下控制光标与点击。
- FR-16 锁屏下输入密码解锁。（平台限制见 [09](09-lock-screen.md)）

### 2.5 配置
- FR-17 灵敏度/反转/手势开关；Server 端口/设备名/开机自启。

## 3. 非功能需求 (NFR)
- NFR-1 延迟：局域网光标移动端到端 < 50ms。
- NFR-2 安全：传输加密；密码不明文存储/传输；防重放。
- NFR-3 跨平台：Win10+ / macOS 12+ / iOS 15+ / Android 9+。
- NFR-4 资源：Server 空闲 CPU<1%、内存<80MB。
- NFR-5 稳定：弱网丢包不崩、可恢复。
- NFR-6 易用：零配置发现，首启引导授权与设密码。
- NFR-7 隐私：纯 LAN，无遥测、不上云。

## 4. 用户故事
- 作为用户，沙发上用手机当触控板看电影。
- 作为演讲者，用手机翻页+激光笔（媒体/快捷键）。
- 作为用户，回家手机解锁电脑而不用走过去（锁屏目标）。
- 作为多设备用户，一台手机切换控制台式机/笔记本。

## 5. 验收（MVP）
- 同 WiFi 自动发现并连，密码错误被拒。
- Win+Mac 已登录会话光标/点击/打字稳定，延迟达标。
- 加密握手成功，抓包无明文密码。
- 锁屏控制至少在 Windows 跑通，macOS 记录现状与限制。
